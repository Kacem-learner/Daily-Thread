# Daily Thread

Welcome to Daily Thread! This project helps you organize and manage your daily activities and discussions.

## Features

- 📝 Create and manage daily threads
- 💬 Organize discussions by topic
- 📅 Track activities day by day
- 🎯 Keep your tasks and thoughts organized

## Getting Started

### Prerequisites
- PHP 7.4 or higher
- Composer
- A modern web browser

### Installation

1. Clone the repository
```bash
git clone https://github.com/Kacem-learner/Daily-Thread.git
cd Daily-Thread
```

2. Install dependencies
```bash
composer install
```

3. Start using Daily Thread!

## Usage

Visit the project to start creating your daily threads and organizing your thoughts.
